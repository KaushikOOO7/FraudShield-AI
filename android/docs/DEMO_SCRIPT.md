# Five-minute FraudShield AI walkthrough

Prerequisite: built/installed debug app with DEMO_MODE=true. This script is not evidence that a device demo has run. Keep the DEMO banner visible. Never call the real emergency helpline for a demonstration.

1. **0:00–0:45:** Welcome and language picker. Explain: “We analyze notifications you allow, caller reputation and links/QR/screenshots you share. We do not listen to calls or read all WhatsApp messages.” Show the separate consent/rationale flow, then Home in manual mode.
2. **0:45–1:45:** Paste the synthetic KYC example from the README, acknowledge Demo consent and Check. Open the HIGH_RISK case, show the shared verdict/gauge, plain reasons, each agent and expandable signals. Explain that scores come from the backend; this staged case is a labeled fixture.
3. **1:45–2:30:** Open graph, tap a node and show entity relationships/PNG sharing. Return to case actions. Open the 1930 dialer and exit without calling; show NCRP and bank-help instructions.
4. **2:30–3:15:** Scan a QR or paste QR content; show it does not submit automatically. Pick a screenshot and explain consent/upload. In Demo, results are synthetic and never investigations of the actual image.
5. **3:15–4:00:** Show history filter/search, local delete confirmation and correction request. Show assistant suggested OTP question and the permanent legal disclaimer, then trends with DEMO visible.
6. **4:00–4:45:** Add a Demo family member with consent and switch sharing on. Show the redacted alert result. Explain that real enrollment/recipient consent must be confirmed by the backend.
7. **4:45–5:00:** Privacy center: monitoring pause, stored counts/export and deletion choices. State the limits: support depends on Android permissions, connectivity and backend availability; no guarantee of complete fraud detection.

For a warning→case demo, prepare the emulator SMS route using PHASE_2_DEVICE_CHECKLIST.md before presenting. Preserve actual device/API/build flags in recordings; a Demo warning proves client plumbing, not model accuracy.
